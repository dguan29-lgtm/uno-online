# UNO 联机对战 · UNO Online

经典 UNO 规则的多人在线网页小游戏。创建房间拿到 4 位房间码，发给好友即可开局，2–8 人同玩。

Node.js + Socket.IO 实现，服务端权威判定，零数据库、零配置， clone 下来 `npm install && npm start` 就能跑。

## 快速开始

```bash
npm install
npm start          # http://localhost:3000
```

输入昵称 → 创建房间 → 把房间码发给好友 → 好友输入房间码加入 → 房主开始。

- **局域网开黑**：好友浏览器直接访问 `http://你的局域网IP:3000`
- **公网游玩**：部署到任意支持 Node 的服务器/平台，或用 `npx localtunnel --port 3000` 之类的内网穿透临时暴露

Windows 用户也可以直接双击 `启动UNO.bat`（自动起服务+开浏览器），`摸鱼模式.bat` 会开无边框小窗。

## 规则（与经典版一致）

- 108 张牌，每人 7 张，按颜色/数字/功能匹配出牌
- 跳过、反转（双人局反转=跳过）、+2、变色、+4 变色
- **+4 质疑**：质疑出牌者手里其实有同色牌——成功则对方罚摸 4 张，失败则自己摸 6 张（12 秒不选择视为接受）
- **喊 UNO**：剩 2 张需先喊 UNO 再出牌，被其他人抓到罚摸 4 张；可以及时"补喊"自救
- 摸牌后只能打刚摸的牌或保留跳过；最后一张是 +2/+4 时下家仍须摸牌计分
- 计分：数字牌按面值、功能牌 20 分、变色牌 50 分，支持连局累计

## 特性

- 🎙️ 斗地主式语音报牌 + 全套音效（出牌/摸牌/回合提醒/UNO/胜利），可一键静音
- 🪑 圆桌座位布局，头像围坐，当前行动玩家金光提示
- 🃏 弃牌堆摊开显示最近出的牌，出牌带飞入动画
- 📋 带玩家名字的行动日志
- 🔌 断线不炸房：自动托管摸牌跳过，同名重新进房即回到座位
- 🐟 内置老板键（`~` 或 📊 按钮）：一键伪装成 Excel 表格，标签页标题同步伪装，伪装期自动静音
- 📱 移动端自适应

## 项目结构

```
uno/
├── game.js      # 纯规则引擎（发牌/判定/功能牌/UNO/质疑/计分）
├── server.js    # Express + Socket.IO：房间管理、广播、断线托管
├── public/      # 前端（index.html / style.css / client.js）
├── test.js      # 引擎冒烟测试：随机模拟数百局校验不变量
├── e2e.js       # 端到端测试：两个真实 socket 客户端打完整局
└── *.bat        # Windows 一键启动/关闭脚本
```

## 测试

```bash
npm test           # 引擎测试
node e2e.js        # 端到端测试（需服务器已启动）
```
